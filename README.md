# Рабочий Telegram

Telegram, в котором видны только рабочие папки. Личные чаты здесь не показываются, не открываются, не находятся поиском и не присылают уведомлений. Сам Telegram и аккаунт при этом не меняются.

Адрес: **https://sonya1995.github.io/work-telegram/**

## Как поставить

- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран Домой» и запускай клиент с этой иконки. Входить лучше по номеру телефона: код придёт в обычный Telegram.
- **Mac:** открой адрес в Safari или Chrome и войди по QR-коду из Telegram на телефоне. В Safari можно сделать «Файл → Добавить в Dock», тогда клиент будет как отдельное приложение.

При первом запуске клиент попросит ключи приложения (api_id и api_hash) с [my.telegram.org](https://my.telegram.org/apps), раздел API development tools. Они хранятся только на этом устройстве и не попадают ни в репозиторий, ни на сайт. Чтобы ввести другие ключи, открой адрес с `?reset-keys` в конце.

## Какие папки считаются рабочими

Папка рабочая, если:

- в её названии есть 💼 (например, «Работа 💼»), или
- её название указано при сборке в `WORK_FOLDERS`.

Новая рабочая папка появляется в клиенте сама: достаточно добавить 💼 в её название в любом Telegram.

## Что скрыто

- «Все чаты», архив, нерабочие папки
- личные чаты в поиске, глобальный поиск по каналам, вкладки медиа и файлов в общем поиске
- истории (stories)
- уведомления и звонки из нерабочих чатов
- счётчик непрочитанного считает только рабочие чаты
- в меню нет «Избранного», «Контактов», архива и кошелька

## Из чего сделано

Это открытый веб-клиент Telegram [Telegram Web A](https://github.com/Ajaxy/telegram-tt) (лицензия GPL-3.0) с изменениями из файла `work-mode.patch`. Собранная версия лежит в ветке `gh-pages`.

Пересобрать (нужен Node.js 24+):

```sh
./build.sh
```

Результат появится в папке `site/`, его нужно положить в ветку `gh-pages`.
